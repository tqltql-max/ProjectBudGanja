1.º signo · destaque

Ariana e derivações

Pedido de campo: arianos é o primeiro dos signos? Sim. No zodíaco tropical, Áries abre o ciclo (~21 de março, equinócio). Quem nasce sob esse signo é ariano (m.) / ariana (f.); o plural é arianos / arianas.

Céu verificável

O visor abaixo é Aladin Lite (CDS Estrasburgo) — fotografia do céu (DSS), não um mapa natal. Escolhe um signo; o ecrã aponta à estrela âncora. Google Sky não oferece embed na web — o recorte está na caixa seguinte.

Abrir Aladin numa aba · Stellarium Web · Descarregar KML (Google Earth · Céu)

Google Sky — o que ainda permite integração?

Embed na página: não. O site clássico google.com/sky era um visor Flash/Maps antigo; a Maps Embed API de hoje só cobre Terra (place, view, directions, streetview, search) — não o modo Céu. O plugin do Google Earth para o browser foi descontinuado.

Google Earth (secretária)

Sim, por KML. Um ficheiro com hint="target=sky" pede ao Earth para mudar para o modo Céu. Coordenadas: longitude = ascensão recta em graus − 180; latitude = declinação. O KML deste guia abre nos 12 signos, com Áries (Hamal) à frente. Documentação: Sky Data in KML.

Sky Map (telemóvel)

A app Sky Map (ex-Google Sky Map, agora código aberto) aponta o telefone ao céu. Não é widget para o site. Play Store.

O que o laboratório usa aqui

Aladin Lite — feito para embed, sem chave API, céu de telescópio. Stellarium Web — planetário com traço das constelações, noutra aba. Os dois verificam o céu; nenhum emite horóscopo.

    Cavaleiros do Zodíaco

    Pedido de campo: inspeção em Cavaleiros dos Zodíacos. O lema canónico no Brasil é Os Cavaleiros do Zodíaco (*Saint Seiya*, Masami Kurumada / Toei, 1986). As doze casas seguem a ordem do zodíaco: a primeira é Áries — no manga/anime, o Cavaleiro de Ouro Mu de Áries. O cosmo no ecrã é metáfora de fogo interior; a luz do laboratório é circuito e sol.
