Inspeção: Save Game — gravar a partida; o rasto, não o milagre

Publicado em 23 de agosto de 2026

Escopo

Inspeção editorial de Save Game — composto inglês vivo no menu brasileiro: gravar a partida. Pedido de campo no mesmo sopro: salve tudo / inspeção da palavra Save Game / faça seu melhor. Não é walkthrough. Não é tutorial de pirataria. Objecto = a fórmula de menu e o ofício de não perder o rasto.

Nota metodológica: auditoria independente. Fontes: save, game, salvar, saved game. Ficha ≠ manual de save scum, ≠ cópia ilegal, ≠ cloud de marca. Série Palavras. Solo da língua portuguesa.

Gatilho: Save Game / savegame / salve tudo / salvar o jogo.

O que é o objecto: um botão de memória. O game continua a ser o jogo; o save é o ficheiro do rasto — slot, cartão, nuvem, bateria. Sem save, a partida é só presente. Com save, o passado da sessão ainda cabe amanhã.

Hipóteses e método

H1: Save Game < EN save + game — fórmula de menu, não frase solta (alta).
H2: no BR a boca diz salve tudo / salva aí; o ecrã muitas vezes deixa o inglês.
H3: salvar (pôr a salvo) e gravar (inscrever) são irmãs; o ofício é o mesmo: não perder.
H4: Load Game é a porta de volta; New Game apaga o começo; Save escreve o meio.
H5: backspace corrige o rascunho; Save fixa o rascunho. Eixos opostos.
H6: fui sem save é saída no ar; save + saída é porta.
H7: Faça o seu melhor pede o gesto; Save Game guarda o gesto.
H8: fecho = Valeu !!! · eu amo a vida.
