Inspeção: Árvore de trabalho — working tree; a orelha cola work three

Publicado em 22 de agosto de 2026

Escopo

Inspeção editorial da expressão árvore de trabalho — calco do inglês working tree (git): o chão de ficheiros que se edita. Pedido de campo: inspeção em árvore de trabalho work three. A orelha cola work three (três) em work tree (árvore). O étimo corta.

Nota metodológica: auditoria independente. Fontes: gitglossary · working tree, `git worktree`, Wiktionary · tree, árvore, trabalho, three. Ficha ≠ tutorial git. Ficha ≠ protocolo de silvicultura. Série Palavras.

O que é o objecto: a cópia viva dos ficheiros no disco — onde a mão escreve. Não é o número três. Não é a planta sénior do laboratório.

O que a orelha cola — e o étimo corta

Pedido: work three. Three = inglês três (germ. þrīz). Tree = inglês árvore (germ. trewą) — tree. O número vive na ficha três; aqui só o lapso.

O olho lê TREE / THREE: quase o mesmo desenho. A orelha cola; o étimo solta.

Hipóteses e método

H1: working tree no git é a árvore concreta (ficheiros checked out), não a metáfora da planta.
H2: work three é lapso de campo — indexar, sem humilhar; método gíria / anival gerino.
H3: `git worktree` acrescenta uma árvore; não substitui a árvore principal.
H4: Árvore da Vida fica planta. Esta ficha fica ofício.
H5: commitar grava um corte da árvore; não é a árvore.

Três andares (não misturar)

AndarO que éO que não é
1. Working treeFicheiros no disco que se editamO repositório nuzinho (`.git`) sozinho
2. `git worktree`Segunda (ou terceira) árvore no mesmo repoClonar de novo; «work three» como número
3. CommitSnapshot com rasto — commitarA árvore ainda suja no editor

Irmãos de fluxo: ramo → árvore de trabalho → commitar → push. Esta ficha é só o chão.

Limites

  • Não ensina `git worktree add`, não autoriza dois checkouts a pisar o mesmo ramo à força.
  • Não funde com Árvore da Vida.
  • Work three = lapso, não lema.
  • Working directory no glossário git aponta à working tree — não abrir ficha à parte nesta entrega.
