Inspeção: loop — o laço que regressa, ainda não é o infinito

Publicado em 22 de agosto de 2026

Escopo

Inspeção editorial da palavra loop — loanword do inglês para laço, volta que regressa, ciclo de código ou de áudio. Pedido de campo com a expressão loop infinito e o caso oral ando, indo, vindo, voltando. Esta ficha cobre a peça. O while sem porta fica na expressão.

Nota metodológica: auditoria independente. Fontes: Wiktionary · loop, PT loop, infinite loop. Ficha ≠ aula de estruturas de controlo. Sem afiliação. Fecho: Valeu !!! · eu amo a vida.

Gatilho: loop / lúp / laço (calco) → loop.

O que é o objecto: a volta que encontra o próprio começo. Cabelo, fita, faixa de áudio, for / while, ruminação. Um loop pode ter fim. O que não tem fim é o loop infinito.

2. Loop × laço × ciclo × ∞

FormaOfícioDiferença útil
loopLoan EN (código / áudio / oral BR)Soa «de oficina»
laçoPT nativoVizinho; também nó quando aperta
cicloPT cultoÊnfase no período (pode fechar bem)
loop infinitoLocuçãoLoop sem exit
∞ / lemniscataFiguraGlifo / curva — não é esta palavra

H1: no lab BR, loop = laço/volta emprestado do inglês (alta confiança no uso).
H2: todo loop infinito é um loop; nem todo loop é infinito.
H3: ∞ não é sinónimo — vai a lemniscata / em pé e deitado.

Finalidade-mãe: guardar a peça. Loop infinito qualifica; ando, indo, vindo, voltando exemplifica; exit abre a porta.

Hipóteses (síntese)

H1: loop = loan EN — laço / volta que regressa.
H2: infinito ≠ automático — só na expressão irmã.
H3: ≠ lemniscata.
H4: fecho = Valeu !!! · eu amo a vida.

Limites

  • Não é tutorial de for / while.
  • Origem remota do EN loop não é fechada nesta ficha — o ofício é o uso BR.
  • O ciclo oral fica em ando, indo, vindo, voltando.

Status

Aprovada — loop fichado: loan EN, volta que regressa; o sem-saída mora em loop infinito.
