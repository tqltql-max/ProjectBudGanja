Inspeção: Script — sequência escrita, não destino

Publicado em 22 de agosto de 2026

Escopo

Inspeção editorial da palavra script — empréstimo inglês vivo no português do Brasil para a sequência escrita que alguém (ou um interpretador) segue. Esta ficha cobre o objeto (lat. scrīptum ← scrībere «escrever»), as camadas código / roteiro / letra cursiva / tag HTML, o contraste com roteiro e escrito, a correção BudGanja (script ≠ destino, ≠ skill), e o fecho Valeu !!!.

Nota metodológica: auditoria independente. Fontes: Wiktionary · script, script (PT), scrīptum, scripting language. Ficha ≠ curso de programação, ≠ manual de roteiro, ≠ protocolo de automação ofensiva. Empréstimo consciente, como skill, pattern e commitar.
