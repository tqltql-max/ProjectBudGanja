Inspeção: JavaScript — Java + Script; o + é cartaz, não sangue

Publicado em 25 de agosto de 2026

Escopo

Inspeção editorial da palavra JavaScript — composto inglês Java + Script. Pedido de campo: java + sCRIPT (a boca parte o camelCase). Dois núcleos. Um + de cartaz. A orelha cola: «é o Java em script». O étimo corta.

Objecto = o nome da língua do browser e do Node desta casa. Não é a língua Java. Não é o café da ilha. Não é o script sozinho (sequência escrita). O mais junta um íman de marca (Java, 1995) a um género (scripting language). Fecho: Valeu !!! · eu amo a vida.

Nota metodológica: auditoria independente. Fontes: Wiktionary · JavaScript, JavaScript, Java, script, ECMAScript. Ficha ≠ curso de programação, ≠ tutorial de injecção, ≠ aula de Java. Irmãs: script · JSON · node · for / if / else. Composto-irmão: homepage (home + page). Fecho: Faça o seu melhor · Valeu !!! · eu amo a vida.

Gatilho: JavaScript / javascript / JS / java + script / ECMAScript / LiveScript / Mocha (codinome 1995) → lema JavaScript. Java sozinha → não é este lema (outra língua). script sozinho → script.
